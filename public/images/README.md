# Images Directory

This directory should contain the school's actual images for the landing page.

## Required Images

Place the following images in this directory to replace the colored placeholders:

### 1. studying.jpg
- **Dimensions**: 1920x1080 (16:9 ratio)
- **Content**: Students studying in classroom or library
- **Style**: Well-lit, showing engaged students

### 2. sports.jpg
- **Dimensions**: 1920x1080 (16:9 ratio)
- **Content**: Students participating in sports activities
- **Style**: Dynamic, showing action and movement

### 3. excursion.jpg
- **Dimensions**: 1920x1080 (16:9 ratio)
- **Content**: Students on educational excursion/in a park
- **Style**: Students enjoying outdoor learning, smiling, happy

### 4. community.jpg
- **Dimensions**: 1920x1080 (16:9 ratio)
- **Content**: School assembly, group activities, community events
- **Style**: Inclusive, showing diversity

## Image Guidelines

### Technical Requirements
- Format: JPG or PNG
- Resolution: 1920x1080 pixels (minimum)
- File size: Under 500KB per image
- Color space: sRGB

### Content Guidelines
- **No identifiable faces** of students (privacy protection)
- **Well-lit** environments
- **Professional quality**
- **School appropriate** content
- **Diverse and inclusive** representation

### Alternative: Use Stock Photos

If you don't have real photos yet, you can use free stock photo websites:
- Unsplash.com (free, high quality)
- Pexels.com (free, no attribution required)
- Pixabay.com (free, high quality)

Search terms: "students studying", "school sports", "school field trip", "school assembly"
